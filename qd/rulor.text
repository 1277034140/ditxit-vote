请帮我生成一个单文件网页工具，用于桌游 Dixit 的裁判和计分。

要求：

1 技术限制

* 只使用 HTML + CSS + 原生 JavaScript
* 不使用任何框架
* 所有代码放在一个 html 文件中
* 不需要后端
* 不需要数据库
* 数据存在内存即可

2 功能

玩家管理

* 输入玩家名字
* 添加玩家
* 至少3人才能开始

游戏流程

每轮：
1 自动指定讲述者（按顺序轮换）
2 其他玩家依次投票
3 投票目标是卡牌编号（1-N）
4 投票结束后输入正确卡牌编号
5 系统自动计算得分

Dixit计分规则：

情况1
如果所有人猜对 或 没有人猜对
讲述者 0分
其他人 +2分

情况2
如果部分人猜对
讲述者 +3
猜对的人 +3

额外规则
如果有人投票给你的卡
你 +1分

UI要求

* 手机优先设计
* 页面宽度500px以内
* 操作简单
* 包含排行榜
* 显示当前轮数
* 显示当前讲述者

代码要求

* 代码清晰
* 变量命名规范
* 添加简单注释
* 不要超过400行代码
